# Lox in OCaml

This is my implementation of the Lox language from Robert Nystrom's [Crafting Interpreters book](https://craftinginterpreters.com/). Specifically, in this repository I'll just be implementing the first half of the book, what in the book is implemented in java (jlox) in OCaml and probably moving to a lower level language with manual memory management for the second half.
